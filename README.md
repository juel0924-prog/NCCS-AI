# 온도

나를 이해하고, 나만의 방식으로 작은 변화를 시작하는 자기 돌아보기 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나 저장소 루트에서 정적 서버를 실행합니다.

```sh
python3 -m http.server 8000
```

그다음 `http://localhost:8000`에 접속합니다. 별도 패키지 설치나 빌드 과정은 없습니다.

## 현재 동작 범위

- 오늘의 체크인, 생활 패턴 요약, 작은 변화와 실천 기록, 대화 파트너 이름이 브라우저의 `localStorage`에 저장됩니다.
- 해/달 버튼으로 밝은 테마와 다크 테마를 전환할 수 있으며, 테마 선택도 저장됩니다.
- 처음에는 다크 테마로 열리며, 오늘 화면에서 짧은 실천을 골라보는 미니 미션을 제공합니다.
- 계정·서버 동기화는 연결되어 있지 않아 기록은 저장한 브라우저에서만 확인할 수 있습니다.
- 마음 대화는 기록에 근거한 로컬 가이드 응답을 사용하며 외부 AI 서비스에는 연결되어 있지 않습니다.
